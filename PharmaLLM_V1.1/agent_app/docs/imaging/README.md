# 影像工作区

支持 NIfTI 与 DICOM 影像解析，上传后附加到输入框，点击“查看”打开右侧工作区。已发送附件从输入框清除，历史消息仍保留入口。

左上轴位、左下冠状位、右下矢状位，右上显示已完成 mask 的三维体素边界表面。支持窗宽窗位、平移缩放、标签叠加与下载；完成的新结果会自动更新工作区。

通过自然语言匹配已注册的分割任务，不能任意指定尚未接入的部位或模型。当前适配单通道 T1 股骨头与髋臼任务。

体积基于原始 mask、影像 affine 和有效空间单位计算，独立于网页三维显示简化。未提供正确空间单位时不输出伪造的测量结果。
